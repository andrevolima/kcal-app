# Registros de decisões arquiteturais

Use este diretório para ADRs (Architecture Decision Records) de decisões relevantes e difíceis de reverter.

Nome sugerido: `NNNN-titulo-curto.md`.

Cada ADR deve conter:

1. título e status (`proposta`, `aceita`, `substituída`);
2. contexto e problema;
3. opções consideradas;
4. decisão e justificativa;
5. consequências e riscos;
6. data e, quando aplicável, ADR substituído.

Decisões inicialmente pendentes incluem autenticação, fórmula do PPN, migração do frontend para TypeScript, armazenamento de arquivos e estratégia de tarefas assíncronas.
